# Exercise Bank

## Beginner exercises

1. Implement a bubble sort by hand and trace it on `[5, 1, 4, 2, 8]`.
2. Explain why insertion sort is nice for nearly sorted data.
3. Sort a list of trade prices from lowest to highest and then from highest to lowest.
4. Create a list with duplicate values and explain what is meant by stable sorting.

## Intermediate exercises

1. Compare merge sort and quick sort on reverse-sorted inputs.
2. Build a simple market signal ranking system using a score list.
3. Rank portfolio positions by performance and explain the trade-off between sorting and selection.
4. Use the order book to simulate a sequence of buy and sell orders.

## Advanced exercises

1. Benchmark each algorithm on random, nearly sorted, reverse-sorted, and duplicate-heavy inputs.
2. Explain why counting sort is not a universal sorting solution.
3. Design a top-k execution engine that keeps only the best-performing trade opportunities.
4. Explain how sorting influences search and retrieval costs in large data systems.

## Reflection prompts

- Why is a stable sort important in some data systems?
- Which algorithm would you choose for a real-time trading feed and why?
- What changes if your dataset is mostly sorted versus completely random?
- How does algorithm choice affect both correctness and speed?
